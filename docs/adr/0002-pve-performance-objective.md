# ADR 0002：以整局胜率和排行榜积分为首要目标

## 状态

已接受，2026-09-14。

## 背景

比赛以抵御机器人、完成任务和生存表现为主要得分来源，但每局仍由两队同场进行上下两个半场，下半场交换位置。半场由基地存活与表现分判胜，一胜一负时比较两半场总分；整局胜、平、负分别获得 3、1、0 个排行榜积分。

## 决策

Astra 首先最大化整局胜率和排行榜积分，在不降低胜率的候选间最大化两半场表现分。表现分由生存分、任务分和机器人击杀分组成。`targetTeam` 等于我方阵营时提高防守权重，其他机器人仍可被攻击以获得击杀分。经济与升级的价值由它们对胜率及上述三类得分的贡献衡量。

平台 LLM 主要用于自然语言任务和自进化任务。确定性的经济、导航、战斗和协议检查继续由 C++ 执行，不消耗模型调用额度。

## 结果

策略不能把该赛制当作单队沙盒：对手、换边和两半场合计分都会影响最终胜负。首版仍以可验证的机器人防守和自身得分为主，协议完整解析 `teamEnemy` 和 `targetTeam`，为后续基于真实回放加入对手响应保留观测。
