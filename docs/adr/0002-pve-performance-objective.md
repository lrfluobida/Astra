# ADR 0002：以 PVE 表现分作为唯一目标函数

## 状态

已接受，2026-09-14。

## 背景

公开任务书包含双队同场和胜负判定描述，早期设计因此保留了 PVP 收益假设。用户随后确认实际参赛赛制为 PVE，最终按表现得分排名。

## 决策

Astra 以生存分、任务分和机器人击杀分的预期总和作为策略目标。`targetTeam` 只表示机器人对基地的紧迫威胁：等于我方阵营时提高防守权重，其他机器人仍可被攻击以获得 PVE 击杀分。经济与升级的价值由它们对上述三类得分的贡献衡量。

平台 LLM 主要用于自然语言任务和自进化任务。确定性的经济、导航、战斗和协议检查继续由 C++ 执行，不消耗模型调用额度。

## 结果

策略不再为了压制对手、帮助另一方防守或推测两队分差而行动。协议仍完整解析 `teamEnemy` 和 `targetTeam`，以兼容平台请求并保留可观测障碍信息。
