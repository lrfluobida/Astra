# ADR 0003：从基地推导三火箭镜像布局

## 状态

已接受，2026-09-15。

## 背景

地图为 41×32，坐标原点在左下角。基地是 2×2 建筑，其 `pos` 表示左上角；基地周围一圈为武器建造区，外侧一圈为围墙建造区。用户指定开局建造三座火箭发射台，其中一座靠近刷怪压力方向、两座远离，并优先升级远端火箭。当前资料没有给出刷怪点的精确坐标。

## 决策

Astra 根据基地占地直接推导 12 格武器环和 20 格围墙环。刷怪点未知时，以基地指向地图中心的方向作为压力侧：近端火箭放在压力侧角点，两座远端火箭放在相反角点及其相邻格。该局部几何在双方换边后精确做 180° 镜像，不写死某一阵营的绝对坐标。

三座火箭按远端、远端、近端顺序建造。全部建成后，升级顺序为两座远端从 1 级升到 2 级、两座远端从 2 级升到 3 级，最后按相同方式升级近端。购券和使用券由同一持券工人持续执行，另一工人保留经济能力。

## 结果

首日 75 金币可以全部用于三座火箭，且上下半场使用同一套镜像算法。地图中心只是缺少刷怪坐标时的代理；取得平台回放后，应对照机器人首夜出现位置验证压力侧并替换代理，不改变建造区推导和升级状态机。
